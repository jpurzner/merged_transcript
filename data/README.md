# data/

Datasets for the merged GNP transcript timecourse. The **shipped** files are
the source of truth for the API and figures; the **rebuilt/intermediate** files
are regenerated by the pipeline and git-ignored.

## Shipped (committed)

| File | Produced by | Contents |
|------|-------------|----------|
| `toc_t50_2023_05_17.txt` | canonical (2023 run) | The full merged per-transcript table — 24,630 rows × 115 columns. Every kinetic metric, significance value, expression call, and category. Source of truth for the query index. |
| `timecourse_query_index.tsv` | `R/04_build_query_index.R` | Slim, query-optimized index (one row per transcript, gene symbol key, 27 columns) derived from `toc_t50`. What `query_gene.R` reads. |
| `log2_norm_list_shift.RData` | `R/02_align_timecourse.R` | The per-replicate **aligned** log2 expression matrices — `list(scott 20562×11, hatten 20562×18)`, row-normalized to log2 fold change and shifted onto the shared pseudo-time axis. This is what the plotting layer consumes. |
| `gene_classification.tsv` | from `Ezh2_2022/sce_contaminant_full.txt` | Slim classification table for the Sankey (`R/figures/sankey_classification.R`): `toc_t50` kinetics (`avg_fc`, `avg_max`, `avg_min`, `t50_cat`, `expr`, `max_cat`) plus the scRNA-seq–derived lineage/cell-cycle columns (`group_1`, `group_2`, `exclude_cat`) that are NOT in `toc_t50`. One row per transcript. |
| `raw/README.md` | — | Provenance of the raw inputs (the raw files themselves are symlinked and git-ignored). |

## Rebuilt / intermediate (git-ignored, regenerate on demand)

| File | Produced by | Contents |
|------|-------------|----------|
| `normalized_merged.RData` | `R/01_normalize_and_merge.R` | Stage-1 handoff: `RNAseq_list` (Scott DESeq2-normalized counts + Hatten linear intensity on shared transcripts), `meta_list`, `pval_all` (annotation + per-dataset min adjusted p-value). |
| `alignment_datasets.RData` | `R/02_align_timecourse.R` | **The alignment datasets** — a named list bundling every stage of the normalization→alignment (see below). |
| `toc_t50_rebuilt.txt` | `R/02_align_timecourse.R` | The rebuilt merged table. Reproduces the canonical kinetics exactly (t50/fold-change/time-of-max r = 1); categorical class calls agree ~93% (difference is only the expression-binarization cutoff). |
| `log2_norm_list_shift_rebuilt.RData` | (legacy) | superseded by `log2_norm_list_shift.RData`. |

### `alignment_datasets.RData` — the alignment bundle

`load()` gives a single list `alignment_datasets` with:

| Element | What it is |
|---------|-----------|
| `log2_norm_list` | per-replicate log2 fold change vs each gene's own mean (Scott 11, Hatten 18 cols) |
| `log2_norm_avg_list` | the above averaged within each time point |
| `interp` | each dataset interpolated onto the full E15…P56 **day axis** (63 columns) |
| `interp_align` | interpolated series **aligned** (2nd shifted to match overlap) and zero-centred per gene |
| `interp_align_avg` | the two aligned series averaged together |
| `shift` | the per-gene shift applied during alignment |
| `log2_norm_list_shift` | per-replicate data with the alignment shift applied — used for plotting |
| `meta_list`, `pseudo_time`, `time_ref` | the design metadata (time labels, pseudo-time order, day↔dataset map) |

## Regenerating

```bash
Rscript R/run_pipeline.R --step merge   # normalize -> align (needs data/raw/)
Rscript R/run_pipeline.R --step index   # rebuild the query index from toc_t50
```

The alignment datasets regenerate **bit-identically** to the shipped
`log2_norm_list_shift.RData` (max difference ~4e-15).
